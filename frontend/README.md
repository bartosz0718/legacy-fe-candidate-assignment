# Frontend – Web3 Message Signer & Verifier

This is the **React (CRA) + TailwindCSS** frontend for the Decentralized Masters test task.  
It implements **Dynamic.xyz headless authentication**, embedded wallet creation, and message signing.

---

## ✨ Features
- **Headless Email OTP login** (Dynamic.xyz SDK)
- **Embedded non-custodial wallet** auto-creation
- **Custom message signing** with connected wallet
- **Signature verification** via backend API
- **Local history** of signed messages (stored in `localStorage`)
- **Modern UI** styled with TailwindCSS + OTP input component (`react-otp-input`)
